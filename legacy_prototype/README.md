# HavenWorld — Legacy Prototype (Deprecated)

> [!WARNING]
> This folder contains the legacy standalone prototype and is **deprecated**. It is retained purely for historical reference and asset preservation.

Active development occurs in the production monorepo workspaces:
- **`apps/client`**: 3D client application built on Babylon.js, TypeScript, and Vite.
- **`apps/server`**: Multiplayer game backend built on Express, Socket.io, Redis, and Prisma (PostgreSQL).
- **`packages/shared`**: Shared protocol definitions, data types, and socket event constants.

Do not add new features or run deployments from this directory.
